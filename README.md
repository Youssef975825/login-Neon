# Neon Glow Login Page

A modern, responsive, and futuristic **Login Page** designed with a stunning Neon Glow effect. This project is built using HTML5 and CSS3, focusing on clean UI/UX and smooth CSS animations.

---

## 🚀 Features
* **Futuristic Design**: Dark mode aesthetic with high-contrast neon highlights.
* **Smooth Animations**: CSS-driven animations for the glow and interaction effects.
* **Fully Responsive**: Works seamlessly across different screen sizes.
* **Clean Codebase**: Organized HTML structure and modular CSS.

---

## 🛠️ Technologies Used
* **HTML5**
* **CSS3** (Animations, Flexbox, Keyframes)
* **Ionicons** (For consistent iconography)

---

## 📂 Project Structure
* `index.html`: Main structure of the login page.
* `style.css`: All styling, neon effects, and keyframe animations.
